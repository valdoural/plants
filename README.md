# Leafy

Личный помощник для растений: распознавание вида по фото, диагностика болезней, «Мой сад» и напоминания об уходе.
Один код на Flutter → Android, iOS и web (PWA — открывается на iPhone через Safari).

Проект для личного некоммерческого использования. Функциональность вдохновлена приложениями-определителями растений,
но код, дизайн, тексты и данные — собственные; распознавание — через публичные API.

## Что умеет (v0.1)

| Раздел | Возможности |
|---|---|
| Распознать (кнопка камеры) | 1–3 фото с камеры или из галереи → варианты вида с уверенностью, похожие фото → карточка вида → «Добавить в сад» |
| Диагноз | Фото проблемного места → вероятность, что растение здорово, вероятные болезни, лечение (профилактика / без химии / препараты), запись в дневник растения |
| Мой сад | Сетка растений, поиск, фильтр по месту (дом / улица / балкон); карточка растения: «Уход», «Дневник» (заметки с фото), «О растении» |
| Напоминания | Полив, подкормка, опрыскивание, пересадка, обрезка, поворот к свету; «Готово» / «Отложить»; группировка «Просрочено / Сегодня / Неделя / Позже»; счётчик на вкладке; **ежедневная сводка-уведомление** в выбранное время (Android/iOS) |
| Главная | Задачи на сегодня, быстрые действия, недавние распознавания, сезонный совет |
| Настройки | Выбор сервиса распознавания с подсказками, API-ключи, язык результатов, подключение Supabase, режим «через сервер» |

Советы Plant.id по свету, почве и ядовитости приходят на английском — приложение показывает короткую русскую
сводку («Яркий рассеянный свет», «Ядовито для кошек, собак»), а оригинал доступен по нажатию.

## Дизайн: «Витрина»

Фото растения — главный элемент экрана, интерфейс тихий: один фон, одни «чернила», один акцент.
Концепты и выбор направления — на холсте дизайна (A3 «Витрина»).

| | Тёмная | Светлая |
|---|---|---|
| Фон | `#0F110F` | `#F6F7F4` |
| Плашки | `#1C1F1B` / `#262A25` | `#ECEEE9` / `#E3E6E0` |
| Текст / второстепенный | `#F3F4F0` / `#A9ADA6` | `#121411` / `#5B6058` |
| Акцент | селадон `#CFE3C8` | тёмно-зелёный `#3E6B45` |
| Главная кнопка | светлая «таблетка» | тёмная «таблетка» |

- Шрифт — Manrope (SIL OFL, `assets/fonts/`), кириллица в комплекте.
- Тема: как в системе / светлая / тёмная — «Ещё → Настройки → Оформление».
- Без рамок и теней: поверхности разделяются шагом тона. Цветом выделяется только вода (полив) и «просрочено».
- Токены — `lib/core/theme.dart` (`LeafyPalette`, доступ через `context.palette`).

## «Для вас» и каталог региона

- **Поиск растений** по русскому или латинскому названию, карточка вида с фото, описанием из Википедии и «Добавить в сад».
- **Ваш регион**: место (геолокация или поиск города), погода на 3 дня и советы по садоводству под прогноз
  (заморозки, жара, дожди, сухой воздух).
- **Тенденции региона**: «Выращивают рядом» (культурные растения у садоводов вокруг), «Сейчас цветёт», дикая природа.
- **Каталог**: домашние растения, цветы рядом, ядовитые, сорняки, деревья — с фото и числом наблюдений рядом.

Источники (бесплатно, без ключей): [iNaturalist](https://www.inaturalist.org) — виды, фото (лицензии авторов указаны
под снимками) и наблюдения; [Open-Meteo](https://open-meteo.com) — погода и поиск городов;
[BigDataCloud](https://www.bigdatacloud.com) — название места по координатам. Место хранится только на устройстве.

## Экраны разных размеров

Телефон — нижняя панель; планшет — узкая боковая; компьютер — боковое меню, «Для вас» в две колонки,
полки растений превращаются в сетки, остальные экраны ограничены читаемой шириной.

## Сервисы распознавания

| | Plant.id (Kindwise) | Pl@ntNet |
|---|---|---|
| Цена | платно, есть пробные кредиты | бесплатно для некоммерческого использования (до 500/день) |
| Вид растения | ✓ | ✓ |
| Советы по уходу, полив, ядовитость | ✓ | — |
| Диагностика болезней | ✓ | — |
| Ключ | https://admin.kindwise.com | https://my.plantnet.org |

Рекомендуемая связка: Pl@ntNet — основной, Plant.id — для диагностики и подробностей. Переключать можно прямо на экране камеры.

## Запуск

```bash
flutter pub get
flutter run -d chrome        # web
flutter run                  # подключённый Android/iOS
flutter test
```

Ключи вводятся в приложении: «Ещё → Настройки». Без Supabase данные хранятся на устройстве
(в браузере — в localStorage; история ограничена 30 распознаваниями).

## Supabase (облако и синхронизация)

1. Создайте проект на https://supabase.com.
2. **Authentication → Sign In / Providers →** включите *Allow anonymous sign-ins*.
3. **SQL Editor →** выполните `supabase/migrations/20261027000000_init.sql` (таблицы, RLS, bucket `photos`).
4. В приложении: «Настройки → Облако» — Project URL и anon/publishable key → перезапустить приложение.
   Либо при сборке: `--dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...`.

### Распознавание через сервер (ключи не хранятся в приложении)

```bash
supabase functions deploy recognize --project-ref <ref>
supabase secrets set PLANT_ID_API_KEY=... PLANTNET_API_KEY=... --project-ref <ref>
```
Затем включите «Распознавать через сервер» в настройках. Это также решает ограничения CORS в браузере.

> Фото в bucket `photos` доступны по прямой ссылке (пути случайные, по UUID). Для личного сада этого достаточно;
> для чувствительных данных переключите bucket в private и используйте signed URLs.

## Android: установка APK

Каждый push в `main` собирает APK: **Actions → Android APK →** последний запуск → **Artifacts → leafy-apk**.
Скачайте на телефон, распакуйте zip и установите (разрешите установку из этого источника).
APK подписан отладочным ключом — для личного использования; для Google Play нужна своя подпись.

## iPhone без App Store

`.github/workflows/deploy-web.yml` собирает web-версию и публикует на GitHub Pages при каждом push в `main`
(в репозитории: **Settings → Pages → Source: GitHub Actions**).
На iPhone откройте ссылку в Safari → «Поделиться» → **«На экран Домой»**.

Ограничения PWA на iOS: нет виджетов и уведомлений по расписанию — задачи видны на главной и в счётчике.

## Структура

```
lib/

  data/        модели, GardenController (Riverpod), хранилища (local / Supabase), распознавание

```
